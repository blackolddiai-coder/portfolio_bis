# Portfolio — Ethan Diai

Site statique HTML/CSS/JavaScript, prêt à publier avec GitHub Pages.

## Publication sur GitHub Pages
1. Créer un dépôt GitHub, par exemple `portfolio`.
2. Importer tous les fichiers et dossiers de ce répertoire à la racine du dépôt.
3. Dans **Settings → Pages**, choisir **Deploy from a branch**, sélectionner `main` et `/ (root)`, puis enregistrer.
4. Attendre la publication et ouvrir l’URL fournie par GitHub Pages.

Le site n’utilise ni framework ni dépendance externe. Les documents sont stockés dans `documents/`. Le rapport de stage et le poster AMFREE ne sont volontairement pas inclus.
